# Security

Report security problems in private: [open a private advisory](https://github.com/loruorg/turmite/security/advisories/new). Do not open a public issue.

Include the version (`turmite version`), the mode (mainnet or testnet), the steps to reproduce and the impact. Remove real keys and customer data.

Details: [turmite.com/docs/report-vulnerability](https://turmite.com/docs/report-vulnerability/).
